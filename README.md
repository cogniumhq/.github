# Cognium Organization Workflows

This repository backs organization workflow templates shown in Cognium GitHub repositories under **Actions -> New workflow**.

## Templates

- `Cognium AI Security Scan`: runs `cogniumhq/cognium-ai-action@v1` and uploads SARIF results to GitHub code scanning.

## Publishing

The public GitHub repository must be named `cogniumhq/.github`. GitHub reads workflow templates from `workflow-templates/`.
